## 🎯 О проекте

Добро пожаловать! В этом репозитории собраны мои решения отборочных и тестовых задач для стажировок в ведущие финтех-компании.

**Главная цель проекта** — показать не просто рабочие куски кода, а глубокий инженерный подход к разработке:
* ✨ **Чистота кода:** Соблюдение стандартов Java Code Style, принципов SOLID и понятное именование сущностей.
* 🛡️ **Надежность:** Проработка крайних случаев (edge cases), валидация входящих данных и безопасная обработка исключений.
* 📊 **Эффективность:** Оптимизация алгоритмов по времени (O) и памяти.
* 🧪 **Покрытие тестами:** Использование JUnit 5 и Mockito для проверки бизнес-логики.

## 📝 Подробные условия задач

### ✏️ Задача 1: Перестройка
* **Цель:** Отработка навыков работы с базовыми математическими операциями, алгоритмами поиска экстремумов (минимумов/максимумов) и расчет геометрических параметров объектов (Bounding Box).
* **Условие:**  
  В команде произошла реорганизация — объединились два отдела. Новые коллеги хотят сидеть рядом, поэтому офису требуется ремонт.
  Прежние места каждого отдела имели форму прямоугольника. Новая площадка должна быть квадратной, а также содержать предыдущие места,
  т.к. некоторые разработчики очень привязаны к ним. К сожалению, размеры офиса ограничены, поэтому зона должна иметь минимальную площадь.
  Строители пытаются посчитать, сколько материала им понадобится для
  ремонта. Для этого им нужно знать итоговую площадь обновленной площадки. Пожалуйста, помогите им.

* **Точка входа (Main класс):** [`com.ekaterinakok.solutions.taskA.ReconstructionDemo`](./solutions/src/main/java/com/ekaterinakok/screening/task1/ReconstructionDemo.java)
